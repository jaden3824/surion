# 수리온

개인의 수리 질문과 경험, 여러 사람의 댓글이 공개 대화로 쌓이는 한국형 전자제품 수리 커뮤니티의 웹 MVP입니다. 사용자는 제품별 게시판에서 글을 빠르게 찾거나 새 글을 올릴 수 있고, 해결한 뒤에는 특정 댓글을 채택하지 않고 실제 해결 과정을 별도 기록으로 남깁니다.

## 실행

Node.js 20 이상과 pnpm이 필요합니다.

```bash
pnpm install
pnpm dev
```

브라우저에서 `http://localhost:3000`을 엽니다. 기본값은 데모 모드이며 데이터는 브라우저의 로컬 저장소에 유지됩니다. 초기 상태로 되돌리려면 마이페이지 설정의 데모 초기화를 사용하거나 로컬 저장소의 `surion-demo-state-v2`를 삭제합니다.

### 실제 회원가입·로그인 로컬 실행

Docker 호환 런타임을 켠 뒤 아래 순서로 실행합니다.

```bash
pnpm supabase:start
cp .env.example apps/web/.env.local
pnpm dev
```

`pnpm supabase:start` 출력의 API URL과 Publishable Key를 `apps/web/.env.local`의 `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`에 입력합니다. 로컬 인증 메일은 실제 외부 메일함으로 발송되지 않고 `http://127.0.0.1:54324`의 메일함에 안전하게 수집됩니다. 이곳에서 6자리 인증번호를 확인할 수 있습니다.

초기 데이터 구조는 `supabase/migrations/202608070001_initial_schema.sql`, 공개 커뮤니티 보완은 `202608070002_public_conversation_and_profile_privacy.sql`, 회원가입·필수 동의·프로필 사진 구조는 `202608070003_auth_onboarding.sql`, API 접근 권한은 `202608070004_api_privileges.sql` 순서로 자동 적용됩니다. 로컬 데이터를 처음부터 다시 만들 때만 `pnpm supabase:reset`을 사용합니다.

회원가입은 카카오 OAuth와 이메일 일회용 인증번호를 사용합니다. Supabase Auth에서 Kakao 제공자를 활성화하고, Supabase가 안내하는 제공자 콜백 주소는 Kakao Developers에, `http://localhost:3000/auth/callback`과 운영 도메인의 `/auth/callback`은 Supabase Redirect URLs에 등록합니다. 연결이 끝난 뒤에만 `NEXT_PUBLIC_KAKAO_AUTH_ENABLED=true`로 바꿉니다. 저장소의 로컬 설정은 인증 링크 대신 6자리 번호를 보내며 번호는 10분 뒤 만료됩니다. 운영에서는 별도 SMTP를 연결합니다. 인증 설정이 없는 환경에서는 성공으로 위장하지 않고 설정 안내를 표시하며, 실제 키와 비밀값은 저장소에 커밋하지 않습니다.

## 주요 화면과 흐름

- 홈: 증상 검색, 빠른 글쓰기, 댓글·공감이 활발한 인기 글, 전문가
- 회원가입: 비회원 열람, 카카오 우선 로그인, 이메일 인증번호 보조, 닉네임·필수 약관·만 14세 이상 확인
- 전체글: 10개 제품별 게시판, 해결 전·해결 완료, 최신·인기·댓글순 목록
- 즐겨찾는 게시판: 계정별 별표 저장, 원래 게시판 순서를 유지한 우선 노출
- 검색: 검색어, 게시판, 브랜드, 진행 상태, 최신·댓글·같은 증상순 정렬
- 글 작성: 질문 또는 해결 경험 선택 → 제품 정보 → 증상 → 사진/확인의 3단계 폼, 모르는 모델 처리
- 글 상세: 글쓴이와 댓글 작성자가 명확히 구분되는 시간순 공개 대화
- 댓글: 일반·전문가 의견 유형이나 채택 없이 누구나 같은 작성 방식으로 참여
- 수리 요청: 해당 글에 유효한 댓글을 남긴 인증 전문가에게만 비공개 요청
- 해결 기록: 글쓴이만 실제 원인, 방법, 비용, 결과를 댓글과 독립해 등록
- 프로필: 실제 계정의 닉네임·소개·선택 사진을 저장하며, 사진이 없으면 성별을 드러내지 않는 기본 아바타를 사용
- 전문가: 인증 상태, 공개 댓글, 도움 반응, 전문 분야를 중심으로 노출하며 접속·활동 중 상태는 공개하지 않음
- 마이페이지·전문가 작업공간·관리자 화면: 질문, 저장, 알림, 요청, 검증, 신고, 모델 정리

## 현재 범위

작동하는 프로토타입을 위해 화면과 핵심 상태 변화는 데모 모드에서도 검수할 수 있습니다. Supabase 환경 변수를 연결하면 회원가입, 세션, 필수 동의와 선택 프로필 사진 업로드는 실제 서버 흐름을 사용합니다. 프로필 사진은 서버에서 512px WebP로 다시 만들어 위치·촬영 정보 같은 원본 메타데이터를 제거합니다. 게시글 첨부 파일, 알림 발송, 결제·정산, 지도·배송 연동은 아직 연결하지 않았습니다. 견적과 결제는 신뢰·분쟁 정책을 검증한 뒤 후속 단계에서 도입합니다.

브랜드 워드마크와 심벌은 제공된 원본 보드의 형태와 색을 기준으로 분리한 PNG를 사용합니다. 한글 본문은 SIL Open Font License의 Wanted Sans를 사용합니다.

## 구조

```text
apps/web          Next.js 웹 애플리케이션
packages/config   서비스명과 브랜드 토큰
packages/contracts API 입력 검증 스키마
packages/domain   역할·수리 요청·검증 업무 규칙
packages/ui       앱 확장을 위한 공용 UI 패키지
supabase          데이터베이스 스키마와 시드
tests/e2e         핵심 사용자 흐름 테스트
docs              제품 규칙과 구조 결정 기록
```
