# 수리온

개인의 수리 질문과 경험, 여러 사람의 댓글이 공개 대화로 쌓이는 한국형 전자제품 수리 커뮤니티의 웹 MVP입니다. 사용자는 제품별 게시판에서 글을 빠르게 찾거나 새 글을 올릴 수 있고, 해결한 뒤에는 특정 댓글을 채택하지 않고 실제 해결 과정을 별도 기록으로 남깁니다.

## 실행

Node.js 20 이상과 pnpm이 필요합니다.

```bash
pnpm install
pnpm dev
```

브라우저에서 `http://localhost:3000`을 엽니다. 공개 사례 화면은 샘플 데이터를 읽기 전용으로 보여 주며, 아직 서버로 이관하지 않은 커뮤니티 작성 상태는 브라우저의 로컬 저장소에 유지됩니다. 초기 상태로 되돌리려면 마이페이지 설정의 데모 초기화를 사용하거나 로컬 저장소의 `surion-demo-state-v2`를 삭제합니다.

### 실제 회원가입·로그인 로컬 실행

수리온은 Vercel Marketplace의 Neon Postgres, 그 데이터베이스 위에서 동작하는 Better Auth, Vercel Blob을 사용합니다. 프로젝트에 접근 권한이 있는 환경에서는 아래처럼 암호화된 개발 환경 변수를 받은 뒤 실행합니다.

```bash
vercel link
vercel env pull apps/web/.env.local --environment=development
pnpm db:migrate
pnpm dev
```

공개 저장소만 내려받은 환경에서는 `.env.example`을 참고해 별도 Neon/Vercel Blob 리소스를 연결해야 합니다. 데이터베이스 주소, Blob 토큰, 세션 서명 키는 Git에 커밋하지 않습니다. `BETTER_AUTH_SECRET`은 32자 이상의 충분히 긴 임의 문자열로 만들고 배포마다 바꾸지 않습니다. 로컬의 `BETTER_AUTH_URL`은 `http://localhost:3000`, 운영 환경은 실제 HTTPS 주소를 사용합니다.

회원가입과 로그인은 실제 이메일·비밀번호 세션을 사용합니다. 신규 사용자는 12자 이상의 비밀번호, 공개 닉네임, 만 14세 이상 확인, 이용약관과 개인정보 필수 동의를 한 번에 제출합니다. 서버가 모든 항목을 검증한 뒤에만 계정과 프로필을 만들며, 프로필 저장이 실패하면 방금 만든 인증 계정도 정리합니다. 전화번호·성별·주소는 수집하지 않고 프로필 사진은 가입 후 선택해서 올릴 수 있습니다.

로그인·가입·탈퇴 요청에는 데이터베이스 기반 요청 횟수 제한을 적용합니다. 로그인 실패는 계정 존재 여부를 드러내지 않는 공통 문구로 안내하고, 세션은 운영 환경에서 HttpOnly·Secure 쿠키로 유지합니다. 사용자는 프로필 설정에서 현재 비밀번호를 다시 확인한 뒤 계정·프로필·프로필 사진을 삭제할 수 있습니다.

현재 공개 프로토타입은 메일 발송 서비스를 별도로 연결하지 않았으므로 가입 확인 메일과 비밀번호 재설정 메일을 제공하지 않습니다. 정식 운영 전에는 전용 메일 공급자를 Better Auth에 연결하고 이메일 소유 확인·비밀번호 복구를 활성화해야 합니다. 준비되지 않은 카카오 버튼은 노출하지 않습니다.

## 주요 화면과 흐름

- 홈: 증상 검색, 빠른 글쓰기, 댓글·공감이 활발한 인기 글, 전문가
- 회원가입: 비회원 열람, 이메일·비밀번호, 닉네임·필수 약관·만 14세 이상 확인
- 전체글: 10개 제품별 게시판, 해결 전·해결 완료, 최신·인기·댓글순 목록
- 즐겨찾는 게시판: 계정별 별표 저장, 원래 게시판 순서를 유지한 우선 노출
- 검색: 검색어, 게시판, 브랜드, 진행 상태, 최신·댓글·같은 증상순 정렬
- 글 작성: 질문 또는 해결 경험 선택 → 제품 정보 → 증상 → 사진/확인의 3단계 폼, 모르는 모델 처리
- 글 상세: 글쓴이와 댓글 작성자가 명확히 구분되는 시간순 공개 대화
- 댓글: 일반·전문가 의견 유형이나 채택 없이 누구나 같은 작성 방식으로 참여
- 수리 요청: 해당 글에 유효한 댓글을 남긴 인증 전문가에게만 비공개 요청
- 해결 기록: 글쓴이만 실제 원인, 방법, 비용, 결과를 댓글과 독립해 등록
- 프로필: 실제 계정의 닉네임·소개·선택 사진을 저장하며, 사진이 없으면 성별을 드러내지 않는 기본 아바타를 사용
- 전문가: 인증 상태, 공개 댓글, 도움 반응, 전문 분야를 중심으로 노출하며 접속·활동 중 상태는 공개하지 않음
- 마이페이지·전문가 작업공간·관리자 화면: 질문, 저장, 알림, 요청, 검증, 신고, 모델 정리

## 현재 범위

회원가입, 로그인, 로그아웃, 세션, 필수 동의, 프로필, 선택 사진 업로드와 회원 탈퇴는 Neon Postgres·Better Auth·Vercel Blob의 실제 서버 흐름을 사용합니다. 프로필 사진은 서버에서 512px WebP로 다시 만들어 위치·촬영 정보 같은 원본 메타데이터를 제거합니다. 커뮤니티 게시글·댓글은 아직 공용 데이터베이스로 이관하지 않았으며 서버 쓰기 API는 저장된 것처럼 응답하지 않고 명시적으로 닫혀 있습니다. 게시글 첨부 파일, 알림 발송, 결제·정산, 지도·배송 연동도 아직 연결하지 않았습니다.

브랜드 워드마크와 심벌은 제공된 원본 보드의 형태와 색을 기준으로 분리한 PNG를 사용합니다. 한글 본문은 SIL Open Font License의 Wanted Sans를 사용합니다.
