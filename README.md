# 수리온

수리 경험과 전문가 답변이 공개 대화로 축적되는 한국형 전자제품 수리 커뮤니티의 웹 MVP입니다. 제품을 검색해 기존 사례를 먼저 찾고, 해결되지 않으면 질문을 작성하며, 공개 답변으로 신뢰를 확인한 뒤에만 전문가에게 비공개 수리 요청을 보낼 수 있습니다.

## 실행

Node.js 20 이상과 pnpm이 필요합니다.

```bash
pnpm install
pnpm dev
```

브라우저에서 `http://localhost:3000`을 엽니다. 기본값은 데모 모드이며 데이터는 브라우저의 로컬 저장소에 유지됩니다. 초기 상태로 되돌리려면 마이페이지 설정의 데모 초기화를 사용하거나 로컬 저장소의 `surion-demo-state-v1`을 삭제합니다.

Supabase를 연결할 때는 `.env.example`을 `.env.local`로 복사하고 공개 URL과 익명 키를 입력합니다. 초기 데이터 구조는 `supabase/migrations/202608070001_initial_schema.sql`, 샘플 데이터는 `supabase/seed.sql`에 있습니다.

## 주요 화면과 흐름

- 홈: 10개 전체 카테고리, 최근 질문, 해결 사례, 답변 대기 글, 전문가
- 검색: 검색어, 카테고리, 브랜드, 진행 상태, 최신·댓글·도움순 정렬
- 질문 작성: 제품 정보 → 증상 → 사진/확인의 3단계 폼, 모르는 모델 처리
- 사례 상세: 질문자·전문가·일반 사용자·관리자의 시간순 공개 대화
- 수리 요청: 해당 사례에 유효 답변을 남긴 인증 전문가에게만 비공개 요청
- 해결 기록: 질문자만 실제 원인, 방법, 비용, 결과를 등록
- 전문가: 인증 상태, 공개 답변, 해결 확인 수, 전문 분야를 먼저 노출
- 마이페이지·전문가 작업공간·관리자 화면: 질문, 저장, 알림, 요청, 검증, 신고, 모델 정리

## 확인 명령

```bash
pnpm typecheck
pnpm lint
pnpm test
pnpm test:e2e
pnpm build
```

## 현재 범위

작동하는 프로토타입을 위해 화면과 핵심 상태 변화는 데모 모드에서 완결되도록 구현했습니다. 실제 이메일 인증, 파일 업로드, 알림 발송, 결제·정산, 지도·배송 연동은 아직 연결하지 않았습니다. 견적과 결제는 신뢰·분쟁 정책을 검증한 뒤 후속 단계에서 도입합니다.

브랜드 워드마크와 심벌은 제공된 원본 보드의 형태와 색을 기준으로 분리한 PNG를 사용합니다. 한글 본문은 SIL Open Font License의 Wanted Sans를 사용합니다.

## 구조

```text
apps/web          Next.js 웹 애플리케이션
packages/config   서비스명과 브랜드 토큰
packages/contracts API 입력 검증 스키마
packages/domain   역할·수리 요청·검증 업무 규칙
packages/ui       앱 확장을 위한 공용 UI 패키지
supabase          데이터베이스 스키마와 시드
tests/e2e         핵심 사용자 흐름 테스트
docs              제품 규칙과 구조 결정 기록
```
