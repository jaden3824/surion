# 제품 및 권한 규칙

## 역할

- 질문자: 자신의 질문 수정, 해결 결과 등록, 조건을 충족한 전문가에게 수리 요청
- 일반 사용자: 공개 의견과 비슷한 경험 등록, 도움 반응, 저장, 신고
- 인증 전문가: 공개 전문가 답변, 추가 정보 요청, 안전 경고, 조건 충족 시 수리 요청 수신
- 관리자: 전문가 검증, 신고 처리, 계정 제재, 카테고리·브랜드·모델 정리

모든 댓글은 하나의 공개 대화에 시간순으로 나타난다. 전문가만 별도 답변 영역에 격리하지 않으며, 작성 당시 역할과 답변 유형을 함께 표시한다.

## 전문가 답변과 수리 요청

수리 요청은 다음 조건을 모두 만족해야 한다.

1. 요청자가 해당 질문의 작성자다.
2. 사례가 해결 또는 미해결 종료 상태가 아니다.
3. 전문가는 개인 또는 사업자 인증을 받았고 수리 요청 수신을 켰다.
4. 해당 전문가가 그 사례에 삭제되지 않은 유효 답변을 남겼다.
5. 같은 사례에 대기 또는 수락 상태의 요청이 없다.

전화번호나 광고 문구만 남긴 댓글은 유효 답변으로 인정하지 않는다. 비공개 요청과 메시지는 요청자, 대상 전문가, 권한 있는 운영자만 접근한다.

## 해결 결과

해결 완료 여부는 질문자만 확정한다. 실제 원인, 해결 방법, 비용, 기간, 현재 작동 여부와 도움을 준 답변을 남길 수 있다. 해결되지 않은 경우에도 종료 이유를 기록해 반복적인 제안을 줄인다.

## 모델 데이터

사용자가 목록에 없는 모델을 직접 입력하거나 모델명을 모르면 임시 모델로 다룬다. 관리자가 기존 모델과 연결하거나 새 모델로 승인하기 전에는 검증된 카탈로그를 자동 변경하지 않는다. 병합 시 질문과 댓글 이력은 유지한다.

## 안전과 운영

- 공개 글에 주소, 전화번호, 송장, 얼굴 등 개인정보를 올리지 않도록 안내한다.
- 감전, 화재, 배터리 팽창 위험이 있으면 직접 분해보다 사용 중단을 먼저 안내한다.
- 신고된 내용은 숨김과 삭제를 구분하고 운영 이력을 남긴다.
- 관리자 상태와 전문가 인증 상태는 본인이 임의로 변경할 수 없다.
- MVP에서는 결제와 정산을 제공하지 않으며, 수리 요청은 수락·거절 흐름까지만 검증한다.
